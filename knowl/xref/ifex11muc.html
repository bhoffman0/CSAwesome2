Activity 12.4.11.

The get_mid(str) method in the StringWorker class should return the middle character if the string has an odd number of characters and the middle two characters if the string has an even number of characters. For example, get_mid("way") should return "a" and get_mid("away") should return "wa".
🔗
public class StringWorker
{
---
    public static String get_mid(String str)
    {
---
        int str_len = str.length();
        int mid = str_len / 2;
---
        /* if odd number of chars */
        if (str_len % 2 == 1)
        {
---
            return str.substring(mid, mid+1);
---
        }
---
        else
        {
---
            return str.substring(mid-1, mid+1);
---
        }
---
    }
---
}
